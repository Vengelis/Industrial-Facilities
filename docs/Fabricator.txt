PERSONNALISER LES CATÉGORIES

Fichier du projet :
src/main/resources/assets/industrial_facilities/fabricator/categories.json

Exemple :
{
  "all_label": "Toutes",
  "uncategorized_label": "Autres",
  "categories": [
    { "id": "panels", "label": "Panneaux", "order": 10 },
    { "id": "blocks", "label": "Blocs", "order": 20 },
    { "id": "machines", "label": "Machines", "order": 30 },
    { "id": "decoration", "label": "Décoration", "order": 40 }
  ]
}

Ajouter ou retirer des entrées ne demande aucune modification Java. "label" est le
nom affiché. "order" détermine la position, par ordre croissant ; à égalité l'ordre
du JSON est conservé. Sans "order", la position dans le JSON sert d'ordre.

Chaque "id" doit être unique, entre 1 et 64 caractères, avec lettres minuscules,
chiffres, tirets, underscores, points ou slashs. L'identifiant "*" est réservé à
l'onglet qui affiche toutes les recettes. Les flèches et la molette au-dessus des
onglets permettent de parcourir toutes les catégories, même lorsqu'il y en a beaucoup.

Une catégorie configurée reste visible quand elle est vide. Une recette dont la
catégorie n'est pas encore déclarée apparaît quand même dans un onglet portant son
identifiant. Une recette sans catégorie apparaît dans "Others" et dans "All".
Une erreur dans categories.json est signalée dans le journal ; la dernière
configuration valide reste utilisable.

Les noms et l'ordre sont des ressources d'affichage côté client. Un pack de
ressources peut remplacer le même chemin assets/industrial_facilities/fabricator/
categories.json. Le serveur définit l'appartenance des recettes aux catégories et
la transmet aux clients avec les recettes.

PERSONNALISER UNE RECETTE

Fichiers : src/main/resources/data/industrial_facilities/recipe/*.json

Exemple de recette personnalisée (coûts uniquement illustratifs) :
{
  "type": "industrial_facilities:fabricator",
  "category": "panels",
  "materials": [
    { "item": "industrial_facilities:empty_sign", "count": 1 },
    { "item": "minecraft:blue_dye", "count": 2 }
  ],
  "result": { "id": "industrial_facilities:cold_sign", "count": 1 }
}
